# Angelisyn Environment

## Purpose
Document development environment requirements and configuration without storing secrets.

## Required Tools
Document required Node.js, pnpm, Git and other tool versions based on repository configuration.

## Environment Variables
For each variable, document:
- name
- purpose
- required/optional
- environment where it is used

Never record secret values.

## Local Development
Document how a developer obtains/configures local environment values.

## CI
Document non-secret CI configuration and required secret names.

## Production
Document production configuration at a high level only. Production secrets must remain in the appropriate secret-management system.
