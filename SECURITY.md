# Security Policy

## Supported Versions

Security updates will be provided for supported releases.

During early development, the latest version is considered supported.

---

## Reporting a Vulnerability

If you discover a security vulnerability,

please report it privately.

Do not create a public GitHub issue.

Include

- Description
- Steps to reproduce
- Impact
- Suggested fix (if available)

---

## Response Process

We aim to

- Acknowledge reports promptly
- Investigate responsibly
- Fix confirmed vulnerabilities
- Credit researchers when appropriate

---

## Scope

Examples include

- Authentication bypass
- Remote Code Execution
- Injection vulnerabilities
- Privilege escalation
- Sensitive data exposure
- SSRF
- CSRF
- XSS

---

## Responsible Disclosure

Please allow reasonable time before publicly disclosing vulnerabilities.
